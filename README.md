# KOC / KOL 合作管理系统

完整的关键意见消费者（KOC）与关键意见领袖（KOL）合作管理框架，涵盖从策略规划、创作者评估、合同签署、内容执行到成效评分的全流程。

---

## 📋 概览

本仓库提供了一套**数据导向、法规合规、流程化管理**的 KOC/KOL 合作方案，适用于：

- 品牌行销团队快速启动影响者合作项目
- 团队成员统一执行标准与评估逻辑
- 长期积累与管理创作者资源库
- 建立可重复、可优化的合作模式

### 核心价值

✅ **完整流程化** — 8 个阶段涵盖从找人到结案的全生命周期  
✅ **数据驱动** — 提供评分模型、成效回推公式、报价评估方案  
✅ **法规合规** — 包含广告法规注意事项与合同范本  
✅ **实务指导** — 话术范本、常见问题解答、案例参考  
✅ **版本管理** — 所有更新都有记录，支持团队协作优化

## 🚀 快速开始（3 分钟）

### 1️⃣ 我要开启一个新的 KOC/KOL 合作案
**第一步**：下载 `templates/02_执行表单集.docx`  
**第二步**：填写「本案规格确认表」（第一张表）  
**第三步**：按照 `docs/01_流程规范.md` 的「阶段 1」继续

### 2️⃣ 我要找合适的创作者
**参考**：`docs/02_数据评估与选择指南.md`  
**使用表单**：`templates/02_执行表单集.docx` 中的「候选名单评估表」

### 3️⃣ 我要给创作者发 Brief
**下载**：`templates/03_合作Brief范本.docx`  
**填写**：根据本案情况调整品牌信息、产品说明、内容需求  
**发送**：发送给创作者，确认他们已理解

### 4️⃣ 我要建立口袋名单库（长期管理）
**参考**：`docs/03_口袋名单管理表说明.md`  
**工具**：在 Google Sheets 按照说明建立（约 30 分钟）

## 🎯 典型使用场景

### 场景 1：新案启动（Day 1-3）
```
1. 开案同仁下载表单集 → 填「本案规格确认表」
2. 主管审核确认  
3. 同仁根据「流程规范」阶段 1-2 开始搜寻创作者
4. 使用「候选名单评估表」记录与筛选
```

### 场景 2：洽谈与签约（Day 4-10）
```
1. 参考「流程规范」阶段 3 进行初步接触
2. 洽谈确认条件后，用「合作Brief范本」编制项目说明
3. 用「合作合约范本」准备合同（主管审核）
4. 发送 Brief 与合同给创作者签署
```

### 场景 3：内容执行与素材收集（Day 11-45）
```
1. 参考「流程规范」阶段 5 管理审稿与修改流程
2. 素材收集完毕后进入「流程规范」阶段 6 授权管理
```

### 场景 4：结案与评分（Day 46-60）
```
1. 完成「执行表单集」中的「合作评分表」
2. 根据评分（80+/60-79/60-）分类到对应的口袋名单
3. 更新 Google Sheets 的口袋名单库
4. 下次新案优先从口袋名单中调用
```

### 场景 5：口袋名单维护（每月）
```
1. 检查「授权到期日」，到期前 30 天提醒续约
2. 定期更新粉丝数与平均互动率
3. 当有新的合作机会时，先在口袋名单中搜寻
```

## 💡 核心概念速查

### KOC vs KOL
| 维度 | KOC | KOL |
|------|-----|-----|
| 粉丝数 | 1K-10K | 10K+ |
| 互动率 | 5-10% | 1-3% |
| 价值 | 真实口碑、素材量大 | 品牌背书、广泛触及 |
| 合作模式 | 产品置换为主 | 付费为主 |

### 合作模式对比
| 模式 | 品牌成本 | 控制度 | 风险 |
|------|----------|--------|------|
| 产品置换 | 低（仅产品成本） | 低 | 创作者可能不重视 |
| 固定费用 | 中（固定支付） | 中 | 内容成效不如预期 |
| 分潤合作 | 低（无前期成本） | 低 | 无法保证销售成效 |
| 保底+分潤 | 中（保底费） | 中 | 平衡成本与风险 |

### 评分标准（合作结案后）
- **80 分以上**：⭐ 优先口袋名单，下次优先洽谈
- **60-79 分**：一般口袋名单，可再合作
- **60 分以下**：观察名单，下次需重新评估

## ❓ 常见问题

**Q: 如何快速了解整个流程？**  
A: 从 `docs/01_流程规范.md` 阅读「整体流程总览」部分（5 分钟）；然后查看「阶段 1-阶段 8」的执行步骤（20 分钟）。

**Q: 我是新员工，第一次要做 KOC 合作，怎么开始？**  
A: 按顺序阅读：
1. 本 README 的「典型使用场景」
2. `guides/第一次合作完整版.md`
3. 跟着下载表单、一步步执行

**Q: 我想评估某个创作者的报价是否合理，怎么做？**  
A: 查看 `docs/02_数据评估与选择指南.md` 中的「业配费用计算与报价评估模型」部分，根据粉丝数、互动率、制作工时反推合理价格区间。

**Q: 如何长期管理创作者资源？**  
A: 建立一个 Google Sheets 的口袋名单库，参考 `docs/03_口袋名单管理表说明.md` 逐步建立（含公式与条件格式设定）。

**Q: 某条款或流程需要修改，我怎么建议？**  
A: 在 GitHub Issues 中开启讨论（可选），或直接创建 Branch + PR 提交修改，写清楚「为什么改」即可。

## 🛠️ 技术说明

### 文件格式
- `.md`：流程规范、指南、说明（直接在 GitHub 网页查看）
- `.docx`：合同、表单、Brief（需下载后用 Word / Google Docs 开启）

### 推荐工具
- **流程规范查询**：NotebookLM（将 `.md` 上传，可一问一答）
- **创作者管理**：Google Sheets（长期维护口袋名单库）
- **协议签署**：DocuSign / Beacon（台湾）或直接 PDF 签署
- **素材管理**：Google Drive / Dropbox（与创作者共享）

### 导出与分享
- 想给某人发「完整规范」？推荐把 `docs/01_流程规范.md` 复制到 NotebookLM
- 想只给创作者看 Brief？直接用 `templates/03_合作Brief范本.docx`
- 想团队一起讨论某个案例？share `examples/` 中的案例文件夹
